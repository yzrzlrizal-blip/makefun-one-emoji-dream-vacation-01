One emoji for one dream vacation: 🌅 — sunrise over the sea. The first light breaking over open water, the moment every dream trip begins: bare feet on cool sand, the whole day still ahead, nowhere to be but here. A postcard in a single character.

## Run it

```sh
python3 main.py
```

`main.py` (pure standard library) reads the emoji from `emoji.txt` and writes it byte for byte to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), then reads the file back and verifies the bytes match.
